# Semiconductor Quantum Dot Simulation Project

This project demonstrates a basic simulation of energy levels in quantum dots (QDs) using the particle-in-a-box model.

## Features
- Python simulation of quantum confinement
- Visual plots showing energy vs QD size
- Relevant theory for understanding semiconductor QDs

## Why this is relevant to QuaNaD Lab
The QuaNaD Lab internship focuses on quantum dots and semiconductor physics. This project showcases:
- Familiarity with quantum mechanical models
- Simulation ability in Python
- Understanding of QD size effects on electronic properties

## Tools
- Python 3
- Jupyter Notebook
- NumPy and Matplotlib

## Getting Started
Run the `QuantumDot_Simulation.ipynb` notebook to explore energy quantization in QDs.
